# monitor-motores-pythom

## relatório sobre o trabalho avaliativo de __*lucas*__

O código funciona atravez de `pythom,html e css`.

importa a função(`datetime`) e  simula uma real inspeção de um motor industrial,dizendo versão do sistema e data da leitura.

monitora 4 motores falando suas versões
sendo elas
1. MTR-01
2. MTR-02
3. MTR-03
4. MTR-04


 e dá informações como temperatura,vibração,rpm e corrente,sendo eles da usinagem,estamparia,bobinagem e pintura e no final dá o resumo do estado dos motores,indicando se está tudo normal ou á anormalidades e tambem calcula as médias
